# Gallery photos

Drop photos here, then add a line for each in `components/galleryItems.js`.
A file with no entry there does not appear on the page — deliberately, so a
stray upload never publishes itself.

- **Any shape.** The grid is a masonry that keeps each photo's own proportions.
- **Under ~400KB.** These load on every visit to the home page.
- **Long side ~2000px** is plenty — the lightbox caps at 78% of viewport height.
- **`.jpg` for photos**, `.png` only if you need transparency.

Everyone identifiable in a photo should be happy for it to be on a public
page. Once deployed these are served to anyone, and search engines index them.
